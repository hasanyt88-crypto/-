# HASCO Pro - زيارات ميدانية

هذه حزمة من ملفات المصدر الحالية للتطبيق كما هي، دون تعديل على التصميم أو الوظائف أو البيانات.

## المحتويات

- ملفات شاشات التطبيق داخل `app/`
- المكونات والسياق والمنطق المساعد داخل `components/` و`context/` و`hooks/` و`lib/`
- ملفات إعداد Expo وTypeScript وBabel وMetro
- ملف HTML الموجود حالياً ضمن `server/templates/`
- ملفات JavaScript وTypeScript وTSX الأصلية
- صورة أيقونة التطبيق داخل `assets/images/`

## ملاحظة

التطبيق الحالي مبني بتقنية Expo/React Native، لذلك لا يحتوي على ملفات CSS مستقلة لمعظم الواجهات؛ تنسيقات الواجهات محفوظة داخل ملفات TSX/TypeScript كجزء من التطبيق الأصلي. لم يتم تحويلها إلى HTML/CSS حتى لا يتغير التصميم أو السلوك.

تم استبعاد مجلدات الاعتماديات والملفات المؤقتة وملفات APK الجاهزة لأنها ليست ملفات مصدرية.
